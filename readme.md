# 云主机管理系统

![版本](https://img.shields.io/badge/版本-1.0.0-blue)
![协议](https://img.shields.io/badge/许可证-MIT-green)

一个现代化的云服务器实例管理系统前端界面，提供直观的可视化管理工具，帮助您高效管理云资源。

## 📋 功能概览

- **仪表盘** - 实时监控系统资源使用情况和关键指标
- **实例管理** - 一键创建、启动、停止和删除云服务器实例
- **存储管理** - 创建、挂载和管理云存储卷和快照
- **网络配置** - 设置网络安全组和访问控制
- **监控统计** - 性能数据可视化和资源使用趋势分析
- **系统设置** - 个性化配置和用户偏好设置

## 🚀 技术栈

- **HTML5 + CSS3**
- **Tailwind CSS** - 实用优先的CSS框架
- **DaisyUI** - 基于Tailwind的组件库
- **ApexCharts** - 响应式、现代化的JavaScript图表库
- **原生JavaScript** - 核心交互和业务逻辑

## 🏗️ 项目结构

```
/
├── index.html             # 主页面
├── css/                   # 样式文件
│   └── style.css          # 自定义样式
├── js/                    # JavaScript文件
│   ├── main.js            # 主要功能实现
│   └── mock-data.js       # 模拟数据
└── images/                # 图像资源
    └── icons/             # 系统图标
```

## 安装与使用

1. 克隆本仓库
2. 使用任何HTTP服务器提供静态文件访问
3. 在浏览器中访问index.html
